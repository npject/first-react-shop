# 🌐 First react shop


## 📝 Description

A simple react shop project built as my first react project.


## ✨ Features

- Product listing
- Single product page
- Cart shopping page
- Header and layout structure
- Not Found page
- Theme / products context


## 🛠 Technologies

- **React 19**
- **JavaScript ES6**
- **React Router**
- **Context API**
- **Font Awesome**
- **Bootstrap 5**


## 📁 Project Structure

- `src/context/` — global state management
- `src/pages/` — application pages and layout structure
- `src/playground/` — experimental learning files
- `src/share/` — reusable UI components


## 💡 Notes

The `playground/` folder contains early experimental files from my learning process.  
They are not part of the main application, but I kept them to show project evolution.


## 🚀 Getting Started
```bash
npm install
npm run start
```
